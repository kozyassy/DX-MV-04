# フェーズ0-① カメラ再校正 — C段階：IPC上の校正データ読取り専用確認

> **作成日**: 2026-09-25
> **目的**: 新プロジェクト `MV-TST00-DX-MV04` での校正作業（B段階）を開始する前に、IPC上に存在する既存プロジェクトの校正データを読み取り、現在の校正状態を把握する。

## 背景

- 計画レビュー（D1-D7）が完了し、新プロジェクト名は `MV-TST00-DX-MV04` に決定した（README.md 計画レビュー完了セクション参照）。
- 校正実施（B段階）前に、既存の校正データの有無と内容を確認し、問題がないか確認する。
- 「読取り専用確認」のため、Mech-Visionの設定を変更してはならない。

## 確認対象プロジェクト

IPC (`192.168.250.20`) 上に以下のプロジェクトが存在するか確認する。

1. `MV-TST00-DX-MV04` （新プロジェクト・未作成の可能性あり）
2. `MV-TST00-DX-MV03` （DX-MV-03からの引き継ぎ）
3. `MV-TST00` （既存プロジェクト）

## 確認項目

各プロジェクトについて、以下の校正データを確認する。

### 1. カメラ内部パラメータ
- 焦点距離 (fx, fy)
- 主点 (cx, cy)
- 歪係数 (k1, k2, p1, p2, k3)

### 2. 手眼校正パラメータ（フランジ-カメラ間変換行列）
- 回転成分 (Rx, Ry, Rz)
- 並進成分 (Tx, Ty, Tz)

### 3. 校正誤差
- Reprojection error (平均、最大、最小)

### 4. 校正メタデータ
- 校正日時
- 校正ボードの種類
- 撮影回数

## 確認方法

1. PC-CからRDP経由でIPC (`192.168.250.20`) に接続する。
2. Mech-Visionを起動し、各プロジェクトを開く。
3. 校正データ画面を開き、上記項目をスクリーンショット撮影する。
4. 校正データファイル（`.calib` 等）が共有フォルダ (`\\192.168.250.20\d\backup` 等) にあれば、そのファイルパス・サイズ・更新日時・SHA-256ハッシュを記録する。
