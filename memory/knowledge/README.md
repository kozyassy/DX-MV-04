# DX-MV-04 ナレッジストア

**この`memory/knowledge/`が、DX-MV-04のナレッジの正本です。**（DX-MV-02と同じ方式を踏襲）

## 構成

| ファイル | 内容 |
|---|---|
| `handoff_state.md` | **【次セッションはまずこれ】** 最新の状態・確定事項・未決事項 |
| `README.md` | 索引と運用ルール |

着手が進むにつれ、DX-MV-02の`memory/knowledge/`（`vis_file_format.md`・`n_trial_operations.md`等に相当するもの）と同様のファイルを、必要に応じてここへ追加する。

## 運用ルール（DX-MV-02と共通）

1. **知見を得たら、その場でこのフォルダのファイルを更新する。** 更新日を本文に入れる。
2. **撤回・訂正は消さずに残す。** 「撤回（→H-###）」と明記する。過去の誤結論を次のセッションが拾い直すのを防ぐため。
3. **一次証跡（Run結果・画面・ロボット姿勢ログ等）は`experiments/`に置く。** このフォルダは解釈と判断を置く場所。
4. 各ファイル冒頭のYAMLフロントマター（`name`／`description`）は維持する。`description`は「何が書いてあるか／いつ読むか」を1行で。
5. **DX-MV-02側の既存知見を参照する場合は、パスを明記し内容を複製しない。**（`C:\Users\y_kozaki\Git_Repo\DX-MV-02\memory\knowledge\`配下）
