# DX-MV-04

DX-MV-04は、DX-MV-03で開始すべき検証内容を引き継ぎ、**DX100 + Mech-Vision によるOn-Hand（ロボット取付カメラ）検証**を継続するプロジェクトである。

## 背景

DX-MV-03で以下の2フェーズを扱う計画が立てられているが、フェーズ0-①（カメラ再校正）の計画案はユーザー未承認・計画レビュー未実施のため実行に移っていない。

1. **① カメラ撮影アングル・距離の誤差量調査**：ロボットにカメラを取り付けた状態で様々な角度・距離から撮影し、3D Matchingによるワーク位置認識の誤差を、ロボットの既知位置を基準とした厳密な相対位置記録のもとで評価する
2. **② ロボット目標位置の誤差評価・改善**：認識結果をロボット座標系へ変換した後の、実際の把持目標位置における誤差量を評価・改善する

## 経緯

- DX-MV-01：基本動作確認（On-Hand環境の座標変換・通信プロトコル確立）
- DX-MV-02：カメラ単体の精度検証（Off-Hand、カメラ座標系のみ）
- **DX-MV-03：On-Hand化後の検証継続**（カメラをロボットに取付、①②の2フェーズを扱う）
- **DX-MV-04：DX-MV-03の検証内容を引き継ぎ、協業で確認すべき検証項目を整理・実行する**

## DX-MV-03から引き継ぐ検証内容

### フェーズ0：基本動作確認

| 項目 | 内容 | 状態 |
|---|---|---|
| 0-① | カメラ再校正（キャリブレーション） | **計画案あり・ユーザー未承認** |
| 0-② | ロボットJOBとの通信確認（101/102通信） | 未着手 |
| 0-③ | `MOV`コメントアウトJOBで1回実行し目標位置算出に異常値が出ないか確認（**物理移動なし**） | 未着手 |

### フェーズ1：純粋なワーク認識位置精度の調査

- 撮影位置（カメラのアングル・距離）を動かしたときの認識位置精度を確認
- **DX-MV-02のA24では「適当に動かしただけ」の簡易検証だったが、今回は位置をパラメータとして定義できる状態（＝ロボットの既知位置を基準に、カメラ移動を厳密にパラメータ化した状態）で実施**

### フェーズ2：姿勢ばらつき課題の確認

- DX-MV-01で未解決のまま残っていた姿勢ばらつき課題（Stage2実験で0.4〜110.8度）
- **目標：** 目標位置算出において精度評価できる段階になったことを確認（＝姿勢が安定して求まる状態にする）
- DX-MV-02で確立した「ワークのZ軸曖昧性」（隣接対称姿勢への飛び）と同種の現象である可能性が高い

### フェーズ3：実機動作確認・精度測定（②）

- 実際にロボットを動かし、**HOME→撮影→目標位置→HOMEに戻る**というJOBの動作を確認
- パラメータを振って、実際の目標位置の精度を測定

## 安全条件（DX-MV-01から引き継ぎ）

- `MVTST00.JBI`（`MOVL P000`を含む）を実行しない
- `MV-TEST.JBI`を変更しない
- 旧MotoPlusプログラムと`Type1`版を同時にロードしない
- ロボット動作を伴う操作は明示的な承認なしに自動化・連続実行しない

3. **DX-MV-03**：フェーズ0-③（MOVコメントアウトJOB実行）の計画
4. **DX-MV-03→DX-MV-04**：承認された計画をDX-MV-04へ引き継ぎ、実行フェーズへ移行
